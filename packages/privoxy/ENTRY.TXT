Package: privoxy
Name: Privoxy
Version: 3.0.19
Section: Internet
Summary: Local web proxy that removes ads and unwanted content
Description: Privoxy runs in the background and filters web pages before the
 browser sees them: it blocks ads and trackers and removes annoying
 scripts. Set your browser's HTTP proxy to 127.0.0.1, port 8118. This is
 the IPv4-only build made for Windows 98. It filters plain HTTP only.
