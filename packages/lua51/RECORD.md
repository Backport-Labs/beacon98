# Lua 5.1.5 (LuaBinaries) - Beacon 98 record

- Date checked: 2026-09-29
- Package: Lua 5.1.5, Windows x86 executables from LuaBinaries (Tecgraf/PUC-Rio)
- Version: 5.1.5 (LuaBinaries 5.1.5 Release 1; the Win32 zip on SourceForge is dated 2014-05-05)
- License: MIT (Lua license); the zip also carries Microsoft's Visual C++ 2005 runtime DLLs
- Recommendation: `lua-5.1.5_Win32_bin.zip`, but only after a VM test (see "Windows 9x support evidence"): nothing in writing says it runs on 98.

## Windows 9x support evidence

- No statement from Lua.org or LuaBinaries about Windows 9x. LuaBinaries' home page (https://luabinaries.sourceforge.net/, opened) says in its history, for 5.1.3 Release 1: "Executables in Windows now uses VC8 (VS2005) run time library (MSVCR80.DLL)". The download page lists `lua5_1_5_Win32_bin.zip` as "Windows x86 Executables" and the dll8 packages as "(Visual C++ 2005 Built)".
- Visual C++ 2005 is, from memory, the last Microsoft compiler whose run-time library supports Windows 98/ME (2008 dropped them). Not confirmed from a Microsoft page in this check.
- Inspection of the binaries (not executed):
  - Every EXE/DLL (lua5.1.exe, wlua5.1.exe, luac5.1.exe, bin2c5.1.exe, lua5.1.dll, lua51.dll, msvcr80.dll 8.00.50727.762, msvcp80.dll, msvcm80.dll) has OS/subsystem version 4.0.
  - lua5.1.exe imports lua5.1.dll, MSVCR80.dll and 13 KERNEL32 functions, including InterlockedCompareExchange (not in Windows 95, present in 98) and IsDebuggerPresent.
  - msvcr80.dll imports only KERNEL32 (160 functions, A and W; the W ones are exported by 98's KERNEL32 as stubs, e.g. GetLongPathNameW) and `_getdrives` from msvcrt.dll.
- Loading problem on 98: the three runtime DLLs are in the subfolder `Microsoft.VC80.CRT` with a manifest. Windows 98 has no side-by-side loader, so it only finds MSVCR80.DLL in the program's folder, the current folder, SYSTEM, WINDOWS or PATH. Beacon must therefore put `Microsoft.VC80.CRT` on PATH (or the DLLs must be copied next to lua5.1.exe). Whether msvcr80.dll then initialises correctly on 98 is not verified.
- Systems: 98 and ME expected (not 95, because of InterlockedCompareExchange). VM test required.

## Security

- NVD CPE cpe:2.3:a:lua:lua:5.1.5: 2 CVEs.
  - CVE-2014-5461: vararg buffer overflow in ldo.c, Lua 5.1 through 5.2.x before 5.2.3, crash (CVSS2 5.0).
  - CVE-2021-43519: stack overflow in lua_resume, 5.1.0-5.4.4, crash via crafted script (CVSS3 5.5).
- Both need a crafted Lua script; Lua runs scripts with full file and os access anyway, so only run trusted scripts.

## Install behaviour

- Plain zip, no top folder:
  `lua5.1.exe`, `wlua5.1.exe`, `luac5.1.exe`, `bin2c5.1.exe`, `lua5.1.dll`, `lua51.dll` (proxy), `*.manifest`, `sample.wlua`, and `Microsoft.VC80.CRT\` (msvcr80.dll, msvcp80.dll, msvcm80.dll, manifest).
- Beacon: unzip into `C:\LUA51` (no spaces, so it can go on PATH in AUTOEXEC.BAT), add `C:\LUA51` and `C:\LUA51\Microsoft.VC80.CRT` to PATH (effective after restart), shortcut to `lua5.1.exe`.
- Uninstall: files. No registry changes.
