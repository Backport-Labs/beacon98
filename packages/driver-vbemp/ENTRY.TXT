Summary: Universal display driver for any VESA 2.0 graphics card
Description: The Universal VBE 9x display driver by Bearwindows and JW Soft
 uses the graphics card's VESA BIOS, so it gives high resolutions and colours on
 cards that have no Windows 9x driver, including many new cards and virtual
 machines. There is no 2D or 3D acceleration. The archive has three versions
 for cards with up to 32, 64 or 128 MB of usable video memory.

Warning: A wrong display driver can stop Windows from starting normally. If
 the screen stays black after the restart, start Windows in Safe Mode (hold
 Ctrl or press F8 while it starts), open Device Manager and change the display

 .
 Use this driver only when your graphics card has no Windows 9x driver of its
 own: the card's own driver is faster.
Notice: The driver files are in {pf}\Drivers\VBEMP, in the folders 032MB,
 064MB and 128MB. Start with 032MB. Open Control Panel, System, Device
 Manager, open your display adapter, choose Driver, Update Driver, "Display a
 list of all the drivers", Have Disk, and enter that folder. Then restart
 Windows. Removing this package does not change the driver Windows uses.
