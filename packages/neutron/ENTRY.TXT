Summary: Tiny clock synchronizer using the Internet Time protocol
Description: Gets the exact time from an Internet time server (Time
 protocol, RFC 868, UDP port 37) and sets the computer's clock. Can sync
 automatically at startup and exit, for use from the Startup folder.
