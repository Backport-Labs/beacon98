Package: kernelex
Name: KernelEx
Version: 4.5.2
Section: System
Summary: Lets many Windows 2000 and XP programs run on Windows 98 and ME
Description: A compatibility layer that adds functions of newer Windows
 versions to Windows 98 and ME, so that programs written for Windows 2000
 and XP can run. It works for all programs and can be switched off per
 program in the file properties.

Warning: KernelEx changes how Windows itself works: it loads a system driver
 and changes Windows functions for every program. If something goes wrong,
 Windows may become unstable or fail to start. Make a backup of your system
 before installing. There are no known security advisories for KernelEx, but
 it has had no security review, and programs made for Windows XP get none of
 XP's protection on Windows 98 and ME.
Notice: Restart the computer to finish installing KernelEx. It is then on for
 all programs; you can change this per program in its file properties.
