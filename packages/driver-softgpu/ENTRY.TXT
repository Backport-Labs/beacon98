Summary: 3D display driver (OpenGL, Direct3D, Glide) for virtual machines
Description: Display driver package by JHRobotics for Windows 95, 98 and ME in
 VirtualBox, VMware Workstation and QEMU. It contains the VMDisp9x display
 driver, Mesa3D for OpenGL, a Direct3D/DirectDraw driver, Glide wrappers, and
 the DirectX 9 runtime (DirectX 8 on Windows 95). Hardware 3D works with the
 VirtualBox VMSVGA and VMware SVGA II adapters; otherwise rendering is done by
 the processor. Choose the preset for your VM software in the setup program.
 .
 The setup files take about 455 MB. Give the virtual machine 1 GB of memory
 for best results.

Warning: A wrong display driver can stop Windows from starting normally. If
 the screen stays black after the restart, start Windows in Safe Mode (hold
 Ctrl or press F8 while it starts), open Device Manager and change the display
 adapter back to Standard PCI Graphics Adapter (VGA).
 .
 SoftGPU is meant for virtual machines. Install your sound driver first:
 sound drivers often replace DirectX files with older versions.
Notice: In SoftGPU setup, choose the preset for your virtual machine and press
 Install, then restart Windows. On Windows 95 setup does not install the
 display driver itself: open Device Manager, your display adapter, Driver,
 Change Driver, Have Disk, and choose the SoftGPU folder. Removing this
 package deletes only the setup files in {pf}\SoftGPU Setup.
