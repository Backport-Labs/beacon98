Package: driver-xhci98
Name: xhci98 USB 3 controller driver
Version: 1.1.1.0
Section: System
Summary: Lets Windows 98 SE and ME use USB 3 (xHCI) ports, at USB 2.0 speed
Description: Open-source driver by Yeo Kheng Meng for the USB 3.0 (xHCI)
 controllers of computers made from about 2012 on, which Windows 98 and ME
 cannot use. Devices work at USB 2.0 speed. It plugs into a USB 2.0 stack
 (USBPORT.SYS), which must be installed first; Beacon cannot provide one.
 Only Windows 98 SE has been tested on real hardware.
Homepage: https://github.com/yeokm1/xhci98

Warning: This is a new driver for the USB controller. On a computer where the
 keyboard or mouse is connected by USB, a failed driver can leave you without
 them; keep a PS/2 keyboard at hand. If Windows does not start, use Safe Mode
 (hold Ctrl or press F8 while it starts) and remove the controller in Device
 Manager. Have the Windows CD ready: Windows asks for its own USB files.
Notice: The driver files are in {pf}\Drivers\xhci98. Open Control Panel,
 System, Device Manager, find the unknown USB controller (often under Other
 devices), choose Driver, Update Driver, "Specify a location", and enter
 {pf}\Drivers\xhci98\RELEASE-X86. Insert the Windows CD when asked, then
 restart. Read {pf}\Drivers\xhci98\readme.txt first. Removing this package
 does not change the driver Windows uses.
