# Avidemux 2.5.2 - Beacon 98 record

- Date checked: 2026-09-29
- Package: Avidemux (Mean and the Avidemux team)
- Version: 2.5.2 (2009-12-19), Qt 4 interface build
- License: GNU GPL version 2 or later
- Needs KernelEx on Windows 98 and ME. Not for Windows 95 (KernelEx does not support 95).
- Recommendation: 2.5.2 with KernelEx. It is the only version with a positive report, and 2.5.3 is reported NOT working even with KernelEx.

## Windows 9x / KernelEx evidence

- MSFN "KernelEx Apps Compatibility List (New)", first post (page downloaded and read 2026-09-29),
  https://msfn.org/board/topic/152471-kernelex-apps-compatibility-list-new/ :
  - under "What is working with KernelEx": "AviDemux 2.5.2, KX 4.0, notes: Loudness adjustment doesn't work"
  - under "What doesn't work": "AviDemux 2.5.3, why: Failed with missing MSVCRT.DLL:_fstat64"
- Operating System Revival, "List of Working Windows 98/ME KernelEx Applications" (downloaded and read 2026-09-29),
  https://retrosystemsrevival.blogspot.com/p/list-of-working-windows-98me-kernelex.html , Video Editors:
  "AviDemux 2.5.2 (KernelEx 4.0) - Volume adjustment does not work."
- KernelEx version: 4.0 in both reports. No compatibility mode is stated (so the default). Beacon ships KernelEx 4.5.2; that combination is not reported, so test it in the VM.
- Both lists say the same thing (OSR states it draws on MSFN), so this is effectively one user report, not two independent ones.
- Why not stock 98: the installer's "Build Info.txt" lists Qt 4.5.3, GTK+ 2.18.3, GLib 2.22.2 and MSVC++ 9.0. None of these support Windows 9x. That KernelEx is needed comes from the reports above; I did not confirm it by testing.
- Older version without KernelEx: I found no primary or forum evidence that any Windows build of Avidemux (2.4.x or earlier) runs on stock 98, and none of the lead lists (MSFN 98SE, MSFN 95, OSR, MDGx) name a native Avidemux. Unknown. 2.4.4 (2009-02-07, avidemux_2.4.4_win32.exe, 13,171,671 bytes, SF MD5 e09ad0122eb3c532803df621cc501eda) exists on SourceForge if someone wants to test it. I did not download it.

## Security

- NVD keyword "avidemux" gives 2 results (CVE-2022-1921, CVE-2026-73433). Both are about the GStreamer "avidemux" element, not this program. There are no CVEs for Avidemux itself.
- The bundled libraries are late-2009 versions with many later-fixed CVEs, for example the FFmpeg snapshot r20602 (many libavcodec/libavformat decoder memory-corruption bugs fixed from 2010 onward) and libpng 1.2.39 (e.g. CVE-2011-3026, heap overflow in png_decompress_chunk, fixed in 1.2.47). I did not make a complete count. Opening crafted video files is the risk.
- Summary: 0 program-specific CVEs. The bundled libraries are outdated and have many known flaws, so give a Warning.

## Install behaviour

- Installer type: NSIS 2.43 (7-Zip reports NSIS-2, LZMA solid; "Build Info.txt": "Packaged with NSIS 2.43").
- Silent switch: standard NSIS `/S` (and `/D=path` last). The Avidemux docs do not document it. The script handles silent mode (`/SD IDOK` on message boxes).
- Default folder: `$PROGRAMFILES\Avidemux 2.5` (from platforms/windows/installer/avidemux.nsi in the 2.5.2 source: `!define INTERNALNAME "Avidemux 2.5"`, `InstallDir "$PROGRAMFILES\${INTERNALNAME}"`).
- Uninstaller: yes. `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Avidemux 2.5`, DisplayName "Avidemux 2.5", UninstallString `$INSTDIR\uninstall.exe` (the uninstall.exe is in the installer listing). Caveat: the script in the tarball still carries the 2.5.1 beta Name strings, so it may not be exactly what built this binary. Verify the DisplayName in the VM.
- Shortcuts: Start Menu "Avidemux 2.5" pointing to avidemux2_qt4.exe; optional Quick Launch and desktop shortcuts.
