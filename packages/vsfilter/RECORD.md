## Install behaviour

- Plain zip holding only `VSFilter.dll`. No installer, no uninstaller.
- The DLL is a COM/DirectShow filter and must be registered: `regsvr32 /s VSFilter.dll` (it exports DllRegisterServer and DllUnregisterServer). Windows 98 has REGSVR32.EXE in the SYSTEM folder.
- Beacon: unzip to `{pf}\DirectVobSub`, then run `{sys}\REGSVR32.EXE /s "{dir}\VSFilter.dll"`.
- Uninstall problem: Beacon's `Uninstall: files` removes the DLL but cannot first run `regsvr32 /u`, so the filter's registry entries stay behind (pointing at a missing file). The format has no pre-removal step; either add one, or accept the leftover entries.
