# VirtualDub 1.10.4 - Beacon 98 record

- Date checked: 2026-09-29
- Package: VirtualDub (Avery Lee)
- Version: 1.10.4 (build 35491, stable, 2013-10-27)
- License: GNU GPL version 2 or later (file `copying` in the release zip is GPL 2; source headers, e.g. src\VirtualDub\source\main.cpp, say "either version 2 of the License, or (at your option) any later version")
- Recommendation: 1.10.4, not 1.5.10. The MSFN list's "1.5.10" is wrong as "last for 9x": the author's own download page says 1.10.4 (the last VirtualDub release of all) requires Windows 98 or later. Windows 95 users need 1.6.19 (not verified here, see below).

## Windows 9x support evidence

- https://virtualdub.sourceforge.net/ (official download page, verified by opening):
  "Microsoft Windows 98, ME, NT4, 2000, XP, Vista, 7, 8, 8.1, Server, or newer; 80486 or higher CPU; 16MB of memory." (requirements for 1.10.4)
  and "Are you still running Windows 95? The 1.7.x and subsequent releases require Windows 98, unfortunately." with 1.6.19 named as the last release for Windows 95.
- https://www.virtualdub.org/blog2/entry_153.html (VirtualDub 1.6.19 release post, opened): "VirtualDub 1.6.x still supports Windows 95 and above" and "1.7.x supports Windows 98 and above".
- https://www.virtualdub.org/blog2/entry_126.html (2006-09-04, "Why don't I drop Windows 98 support?", opened): the author explains he keeps 9x support by not using functions 9x lacks and calling newer ones through GetProcAddress.
- https://www.virtualdub.org/blog2/entry_385.html (search snippet only, not opened): 1.10.4 "finally replaces 1.9.11 as the stable version".
- SourceForge file list https://sourceforge.net/projects/virtualdub/files/virtualdub-win/ (opened): 1.10.4.35491 (2013-10-27) is the newest release; 1.5.10.18160 is from 2003-12-02; there is nothing after 1.10.4.
- Own check of the binary (read from the zip in memory, not run): VirtualDub.exe and vdub.exe have OS/subsystem version 4.0. The import table of VirtualDub.exe uses only functions that exist on Windows 98 (e.g. GetLongPathNameA, TrackMouseEvent, GetCursorInfo, SHGetSpecialFolderPathA from shell32 4.71+, SHDeleteKeyA from shlwapi); GetLongPathNameA is missing on Windows 95, which matches the "98 or later" statement. Wide-character (W) functions are imported too; on 98 they are stubs, so the program presumably picks the A path at run time (not tested).
- Windows ME: named in the official requirements. Windows 95: not supported by 1.10.4; 1.6.19 would be the version for 95 (not downloaded).
- Not tested on a real Windows 98 system (no VM interaction). One VOGONS thread (https://www.vogons.org/viewtopic.php?p=1353033, 2025) only says releases "from before September 4th 2006 are likely to still work under Windows 98"; this is a guess by a forum user, and the author's statement above is the primary evidence.

## Install behaviour

- Installer type: plain zip, no installer and no uninstaller. The zip has no top folder; all files are at the root:
  ```
  VirtualDub.exe (3,152,384)   VirtualDub.vdi   VirtualDub.chm   vdub.exe (command-line)
  vdicmdrv.dll   vdsvrlnk.dll   vdremote.dll   vdlaunch.exe   auxsetup.exe
  aviproxy/proxyoff.reg  aviproxy/proxyon.reg  aviproxy/readme.txt
  plugins32/readme.txt   copying
  ```
- Uncompressed size: 3,973,102 bytes (about 3,880 KB).
- What Beacon must do: `unzip {pf}\VirtualDub` (strip 0), a Start Menu shortcut to `{dir}\VirtualDub.exe`, uninstall by `files`.
- Side effects of the program itself: settings in HKCU `Software\Freeware\VirtualDub` (from general knowledge, not verified); a `files` uninstall leaves them. `auxsetup.exe` optionally installs the AVIFile frameserver and the vdicmdrv.dll codec in the system; Beacon should not run it. Files it installs would not be removed by a `files` uninstall.
- Add/Remove Programs name: none (no uninstaller).
