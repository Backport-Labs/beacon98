# AC3Filter 1.63b (Win9x edition) - Beacon 98 record

- Date checked: 2026-09-29
- Package: AC3Filter (Alexander Vigovsky), DirectShow audio decoder/processor for AC3, DTS, MPEG audio, LPCM, with SPDIF output
- Version: 1.63b, "For Win9x" build (changes.txt: "v1.63b - 11.08.2009")
- License: GNU GPL version 2 (readme.txt), plus an author statement that conflicts with it (see License)
- Recommendation: 1.63b Win9x edition, not 1.46. MSFN's "1.46" is out of date: from 1.60b on the author published a separate "Win9x" edition of each release, the last being 1.63b. **Hosting needs a decision first**: the filter contains DVD CSS descrambling code (DeCSS) and the readme adds a "demonstration and educational purposes" statement. See License.

## License

- readme.txt (1.63b source; the installer installs the same file): "Distributed under GNU General Public License version 2." GPL.txt is the GPL v2 text. Source headers were not all checked for "or later".
- LICENSE.TXT here = readme.txt followed by GPL.txt, both from the 1.63b source zip (the Inno installer could not be unpacked here; its script `ac3filter_win9x.iss` shows it installs exactly these two files from the source tree).
- Redistributing the unmodified binary is allowed by GPL-2.0 s.3 with the license text and the complete source.
- **Problems that need a decision before hosting:**
  1. The readme also says: "This application may solely be used for demonstration and educational purposes. Any other use may be prohibited by law in some coutries. ... This application may be distributed freely unless prohibited by law." This is a disclaimer, but read literally it is a use restriction that GPL v2 s.6 does not allow. Distribution itself is stated to be free.
  2. DVD CSS descrambling: `filter\decss\` (CSSauth.cpp, CSSscramble.cpp, DeCSSInputPin.cpp; the input pin is "Copyright (C) Gabest - December 2002", GPL v2 or later; CSSauth.cpp/CSSscramble.cpp carry no license header) is compiled into ac3filter.ax (referenced in ac3filter.vcproj and used by ac3filter.cpp as the filter's input pin). This is the same kind of code as libdvdcss in VLC: distributing it is restricted in some countries (e.g. the US DMCA anti-circumvention rules). The VLC record flagged the same issue.
  3. Patents: AC-3, DTS, MPEG-1/2 audio decoding and an AC-3 encoder are implemented (author's own valib code). AC-3 and MPEG audio patents have expired; DTS core patents are believed expired (general knowledge, not verified).
- Suggested handling: if Backport Labs decides DeCSS code is acceptable to distribute, host it with the source. Otherwise 1.63b cannot be `external` in the usual sense: the publisher has no server of its own for it any more (ac3filter.net redirects to HTTPS and has no 1.63b link; SourceForge lacks 1.63b; Google's archive is plain HTTP but is not the publisher's server). The fallback is **1.62b Win9x as `external` from the project's SourceForge files**. `http://downloads.sourceforge.net/project/ac3filter/ac3filter/ac3filter_1_62b/ac3filter_1_62b_win9x.exe` answers over plain HTTP with a 302 to `http://master.dl.sourceforge.net/...` (headers checked only; the file was not downloaded; SF MD5 aaaff221b6bd39244f718de727752a49, 2,213,728 bytes). The same approach was used for ffdshow and MPC in this batch.

## Install behaviour

- Installer type: Inno Setup ("Inno Setup Setup Data (5.2.4)" in the exe). Script: `ac3filter\ac3filter_win9x.iss` in the source.
- Silent install: standard Inno switches `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` (not documented by the author; the 2.6.0b changelog mentions a `/noicons` option for later installers only). Language is chosen from the locale (`LanguageDetectionMethod=locale`), so no dialog is expected.
- Default folder: `{pf}\AC3Filter`; start menu group "AC3Filter".
- Installs: ac3filter.ax (registered with regserver), ac3filter_intl.dll, ac3config.exe, spdif_test.exe, `{sys}\ac3filter.acm`, PDF manuals, language files, .reg presets; runs `regedit /s` on Presets.reg and "Reset to defaults.reg"; writes HKCU `Software\AC3Filter`; deletes the DirectShow filter cache key. The ACM driver is registered under `HKLM\Software\Microsoft\Windows NT\CurrentVersion\Drivers32`, which Windows 9x does not use (9x reads SYSTEM.INI [drivers32]), so the ACM part probably does nothing on 98 (not tested). Files are marked RestartReplace, so a restart may be requested if a player has the filter loaded.
- Uninstaller: yes (Inno). `AppID=AC3Filter`, so the key is `...\Uninstall\AC3Filter_is1`; DisplayName is AppVerName = "AC3Filter 1.63b" (Inno default when UninstallDisplayName is not set; the appver define is passed at build time, so the exact string is inferred, not seen).
