Warning: LAV Filters 0.66 is from 2015. Its FFmpeg libraries have many
 security flaws that were fixed later (for example CVE-2016-10190). A
 specially crafted video file could run harmful code in your player. Only
 open files you trust.
Notice: LAV Filters was reported working on Windows 98 with KernelEx in
 Windows XP SP3 mode. If videos do not play, set the XP SP3 mode in KernelEx
 for your player.
