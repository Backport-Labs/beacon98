Package: driver-ahcint
Name: AHCINT SATA AHCI driver
Version: 1.3.0.0
Section: System
Summary: Driver for SATA controllers in AHCI mode (real PCs and VMs)
Description: Driver by ages2001 for SATA AHCI controllers, which Windows 95,
 98 and ME cannot use on their own. Useful on newer PCs whose SATA ports work
 only in AHCI mode, and in VirtualBox with a SATA (AHCI) controller. Without
 it, disks on such a controller run in slow MS-DOS compatibility mode or are
 not found. Windows itself must be installed from a disk the BIOS can reach.
Homepage: https://github.com/ages2001/AHCINT

Installed-Size: 323
Hardware: pci CC_010601
Install: unzip {pf}\Drivers\AHCINT
Uninstall: files
Warning: A wrong disk controller driver can stop Windows from starting and can
 damage data. This driver is new (first release September 2026); back up your
 disk first. If Windows does not start, use Safe Mode (hold Ctrl or press F8
 while it starts), and remove the controller in Device Manager.
Notice: The driver files are in {pf}\Drivers\AHCINT\bin\9X. Open Control
 Panel, Add New Hardware, choose to select the hardware from a list, pick SCSI
 controllers, Have Disk, enter that folder, choose "AHCINT9x SATA AHCI Storage
 Controller" and restart. On the original Windows 95 the controller may show a
 yellow mark; see the project page. Removing this package does not change the
 driver Windows uses.
