# Dev-C++ 4.9.9.2 (with MinGW) - Beacon 98 record

- Date checked: 2026-09-29
- Package: Bloodshed Dev-C++ (Colin Laplace et al.), setup that includes MinGW/GCC
- Version: 4.9.9.2 ("Dev-C++ 5 beta 9 release"), 2005
- License: GNU GPL v2 or later (IDE; header of source/main.pas); bundled GCC, binutils, GDB, make under GPL; MinGW runtime and w32api public domain
- Recommendation: `devcpp-4.9.9.2_setup.exe` (with MinGW: GCC 3.4.2, binutils 2.15.91). The last Bloodshed release; later "Dev-C++ 5" forks (Orwell, Embarcadero) need XP or later.

## Windows 9x support evidence

- SourceForge project summary (https://sourceforge.net/projects/dev-cpp/, opened): "Dev-C++ is a full-featured Integrated Development Environment (IDE) for Win32. It uses GCC, Mingw or Cygwin as compiler and libraries set. It supports Windows 98, NT, 2000 & XP."
- NEWS.txt inside the setup: "Under NT, 2000 and XP, user application data directory will be used to store config files", i.e. 9x is handled separately.
- Binaries inspected in the installer (extracted with 7-Zip, not run): devcpp.exe, Packman.exe (Delphi, packed, subsystem 4.0), gcc/g++/cc1/cc1plus/as/ld/windres/make/mingw32-make/gdb/rm and mingwm10.dll: all OS/subsystem 4.0, ANSI imports from KERNEL32/USER32/ADVAPI32 and msvcrt.dll, nothing from my list of APIs missing on 98.
- Windows 95 and ME: not stated. ME is very likely to work (same Win32 base as 98) but is not claimed.

## Security

- NVD CPE cpe:2.3:a:bloodshed:dev-c++:4.9.9.2 and keyword search:
  - CVE-2007-0643: stack buffer overflow with a long line in a .cpp file, crash and possibly code execution (CVSS2 4.3).
  - CVE-2022-28999: insecure permissions on install folders (CVSS3 8.8). It concerns NTFS permissions; Windows 98 has no file permissions, so it does not apply there.
- The bundled GCC 3.4.2, binutils 2.15.91 and gdb have many later CVEs (mostly crafted object/debug files crashing the tools); not counted.
- Count: 2 for the IDE (1 relevant on 98). Worst relevant: CVE-2007-0643.

## Install behaviour

- Installer type: NSIS 2.25 (7-Zip: "NSIS-2.25"), not Unicode. Silent: standard NSIS `/S`; script (`source/install/devcpp.nsi` in the IDE source) has custom pages but no silent-mode block (not tested).
- Default folder: `C:\Dev-Cpp` (`InstallDir "C:\Dev-Cpp"`).
- Uninstaller: `$INSTDIR\uninstall.exe`, registered at HKLM `...\Uninstall\Dev-C++` with DisplayName `Dev-C++ 5 beta 9 release (4.9.9.2)` (from `!define DISPLAY_NAME "Dev-C++ 5 beta 9 release (${DEVCPP_VERSION})"`).
- Side effects: file associations for .dev, .c, .cpp, .h and others (HKCR), Start Menu shortcuts, HKLM `SOFTWARE\Dev-C++` Install_Dir.
- First start shows a configuration dialog (language, code completion cache).
