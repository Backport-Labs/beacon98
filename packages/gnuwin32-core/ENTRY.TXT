Warning: These are old versions with known security problems. wget 1.11.4
 can be made to overwrite files by a malicious server (recursive FTP
 downloads, HTTP-to-FTP redirects), and its OpenSSL 0.9.8h has dozens of
 known flaws. less and the PCRE library can crash or run code on crafted
 input. Do not rely on wget for secure (HTTPS) connections.
Notice: The tools are in C:\GNUWIN32\BIN, which is added to PATH after a
 restart. On Windows 95, wget also needs the Windows Sockets 2 update.
