Warning: A wrong display driver can stop Windows from starting normally. If
 the screen stays blank after the restart, start Windows in Safe Mode (hold
 Ctrl or press F8 while it starts) and change the display adapter back to
 Standard Display Adapter (VGA).
Notice: The driver files are in {pf}\Drivers\Herc9x. Open Display Properties,
 Settings, Advanced, Adapter, Change, Have Disk, enter that folder and choose
 "Hercules Graphics Card (ISA)". Then restart. Read install.txt there for the
 manual method. Removing this package does not change the driver Windows uses.
