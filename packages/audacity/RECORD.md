# Audacity 2.0.0 (ANSI build for Windows 98/ME) - Beacon 98 record

- Date checked: 2026-09-29
- Package: Audacity (Audacity Team)
- Version: 2.0.0, released March 2012, in the team's separate ANSI (non-Unicode) build "for Windows 98/ME" (`audacity-win-2.0-ansi.exe`)
- License: GNU GPL version 2 or later (README.txt section 1); libraries under GPL-compatible licenses; documentation CC BY 3.0
- KernelEx: not needed. Unicows: not needed (ANSI build, links the ANSI wxWidgets DLLs).
- Recommendation: **2.0.0 ANSI**. It is a stable release and the Audacity Team published it expressly for Windows 98/ME. This settles the disagreement between the lists: 1.2.6, 1.3.7 beta and 1.3.14 beta also had official 98/ME builds, but 2.0.0 is the newest. The confusion comes from the Unicode builds, which need Windows 2000 or later; from 2.0.1 on only Unicode builds were published.
  - Alternative: 1.2.6 (last 1.2.x stable, 2006; "for Windows 98/ME/2000/XP", about 2.2 MB installer). It is smaller and lighter, but older and hit by CVE-2009-0490. It was not downloaded.

## Windows 9x support evidence

- Official Google Code project archive, downloads list (https://storage.googleapis.com/google-code-archive/v2/code.google.com/audacity/downloads-page-N.json, all 107 entries read). The Audacity Team hosted its releases there from 2009 to 2013. Summaries as written by the team:
  - `audacity-win-2.0-ansi.exe`: "Audacity 2.0.0 for Windows 98/ME (installer)"; `audacity-win-2.0-ansi.zip`: "Audacity 2.0.0 for Windows 98/ME (.zip)"
  - `audacity-win-2.0.exe`: "Audacity 2.0.0 for Windows 2000/XP/Vista/7 (installer)" (Unicode)
  - `audacity-win-1.3.14.exe`: "Audacity 1.3.14 for Windows 98/ME (installer)"; the same for 1.3.13, 1.3.12 and 1.3.7. `audacity-win-unicode-*` builds are "for Windows 2000/XP/Vista/7".
  - `audacity-win-1.2.6.exe`: "Audacity 1.2.6 for Windows 98/ME/2000/XP (installer)"
  - 2.0.1 to 2.0.5: only "for Windows 2000/XP/Vista/7(/8)" builds; no ANSI build after 2.0.0.
- https://www.audacityteam.org/download/legacy-windows/ (opened): lists last compatible versions per OS: "Windows 98, ME: Audacity 2.0.0".
- Audacity forum, "Getting Audacity 2.0.0 (or earlier) running on Win98" (https://forum.audacityteam.org/t/getting-audacity-2-0-0-or-earlier-running-on-win98/58042, 2020, opened): one user could not start 2.0.0 or 1.3.4 on his 98 machine (cause not found). The forum helper points out that the site names 2.0.0 as the last version for 98, "assuming the Win 98 OS was fully updated". So it works in general, not on every machine; not tested here.
- Own check of the ANSI build (the official .zip with the same files was read in memory, not run): audacity.exe has OS/subsystem version 4.0. It links the ANSI wxWidgets 2.8 DLLs (`wxmsw28_core_vc_custom.dll`, no "u" suffix = not Unicode) and the Visual C++ 2005 runtime (msvcr80/msvcp80, which still supports Windows 98). Its kernel32/user32 imports are all ANSI or 98-era functions. No unicows.dll is used.
- Installer script `win/audacity_ansi.iss` (in the 2.0.0 source): `MinVersion=4.0,5.0`, i.e. the installer itself starts on 95 and later. Windows 95: no statement from the team; not claimed. Windows ME: named by the team.
- The 1.3.x betas and 2.0.0 have no stated CPU requirement beyond what VC2005 needs; a forum post says SSE2 became required only in 2.1.3.

## License

- LICENSE.TXT here is `LICENSE.txt` from the official 2.0.0 ANSI zip (the installer installs the same file, per audacity_ansi.iss): a note that Audacity is GPL except lib-src code under GPL-compatible licenses, documentation under CC BY 3.0, then the GPL v2 text. README.txt section 1: "either version 2 of the License, or (at your option) any later version".
- Redistribution of the unmodified installer is allowed (GPL-2.0 s.3) with the license text and the complete corresponding source, which we host (below).
- **LAME is not included.** The zip/installer contains no lame_enc.dll; the installer script copies only named files (it says it is explicit "so we don't accidentally distribute avformat.dll"). MP3 export needs the user to fetch LAME separately; Beacon must not bundle it. FFmpeg is not included either (optional separate download; the source only has FFmpeg headers for dynamic loading).
- Bundled components in the Windows build and where their source is:
  - Statically linked libraries from `lib-src/` (all in the full source tarball): libmad (GPL, MP3 decode), libid3tag (GPL), libsndfile (LGPL), libflac (BSD), libogg/libvorbis (BSD), twolame (LGPL, MP2 encode), soundtouch (LGPL), sbsms (GPL), libsamplerate/libresample, expat, portaudio, portmixer, portsmf, libnyquist (BSD), libvamp, etc.
  - wxWidgets 2.8.12 DLLs (custom ANSI build, `*_vc_custom.dll`): wxWindows Library Licence, whose exception allows binary distribution without source; we still host the matching wxWidgets 2.8.12 source (below). Audacity's custom setup.h is in the Audacity source (`win/wxWidgets_additions`).
  - LADSPA plug-ins gverb_1216.dll, hard_limiter_1413.dll, sc4_1882.dll (Steve Harris's swh-plugins 0.4.15, GPL). **Their C source is not in the Audacity tarball**, only the Windows build files (`win/LADSPA_plugins-win/`, readme says "swh-plugins-0.4.15 from http://plugin.org.uk"). plugin.org.uk does not answer any more; the unchanged upstream tarball was taken from Debian's archive (below).
  - Microsoft VC++ 2005 runtime (msvcr80.dll, msvcp80.dll, manifest): Microsoft redistributable, shipped next to the exe. The installer script cites the GPL FAQ system-library reasoning. Allowed under the Visual Studio 2005 redistribution terms (general knowledge; those terms were not opened).
- Patents: MP3 decoding (libmad) and MPEG-1 Layer II encoding (twolame) are implemented; these patents have expired. No AAC/H.264 code is included.

## Security

Source: NVD API 2.0 keyword search "audacity" (6 results), checked against version ranges.
- Affect 2.0.0 (2):
  - CVE-2016-2540: crafted WAV FORMATCHUNK, memory corruption (before 2.1.2), CVSS3 7.8.
  - CVE-2016-2541: crafted MP2 file, memory corruption (before 2.1.2), CVSS3 7.8.
- Not affecting 2.0.0: CVE-2009-0490 (allegro strparse overflow, before 1.3.6; it does affect the 1.2.6 alternative), CVE-2007-6061 (1.3.2 only), CVE-2017-1000010 (2.1.2-2.3.2), CVE-2020-11867 (/var/tmp on Linux).
- Bundled libraries (libsndfile, libFLAC, libvorbis, libmad of 2012 or older) have their own CVE backlogs, not counted here.
- Summary: 2 known CVEs; worst CVE-2016-2540/-2541 (CVSS 7.8), triggered by opening a crafted audio file.

## Install behaviour

- Installer type: Inno Setup ("Inno Setup Setup Data (5.4.2)" in the exe). Script: `win/audacity_ansi.iss` in the source.
- Silent install: standard Inno `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` (not documented by the team). The "Launch Audacity" run entry has `skipifsilent`. Language is chosen from a dialog unless silent (Inno shows the language dialog only in interactive mode). InfoBefore/InfoAfter pages are skipped in silent mode.
- Default folder: `{pf}\Audacity` (`DirExistsWarning=yes`). No Start Menu group; one shortcut `{commonprograms}\Audacity`; optional desktop icon task.
- Registry: associates `.AUP` with "Audacity.Project" (HKCR). `[UninstallRun]` runs `{app}\unins*.*` of earlier installs.
- Uninstaller: yes (Inno). No AppId, so it defaults to AppName: key `...\Uninstall\Audacity_is1`; DisplayName = AppVerName = **"Audacity 2.0"** (Inno default when UninstallDisplayName is not set; read from the script, not seen on a machine).
- Size: the program files are about 24.6 MB unpacked (zip), plus the manual in the installer.
